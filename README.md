# Посмотри в окно

Учебный проект третьего спринта Яндекс Практикума: поиск коротких видео из разных городов по названию и времени суток.

Интерфейс свёрстан по макету на HTML и CSS. Использованы Flexbox, локальные шрифты, псевдоклассы и псевдоэлементы, собственные чекбоксы и доступные состояния фокуса. Логика поиска, загрузки карточек и воспроизведения видео предоставлена в стартовом проекте.

## Запуск

Откройте `index.html` в современном браузере либо запустите локальный сервер в папке проекта, например `python -m http.server 8000` (если установлен Python), и перейдите на `http://localhost:8000`.

Для загрузки видео нужен доступ к интернету. Макет рассчитан на ширину окна от 1200 пикселей.
